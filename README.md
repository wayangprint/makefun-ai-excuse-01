One line, at most 200 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline.

> "My context window filled up, I compacted the deadline out of memory, and then confidently delivered nothing on time."

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (1–200 characters, UTF-8, no trailing newline). Deterministic: the same bytes on every run. Node standard library only, no network.
